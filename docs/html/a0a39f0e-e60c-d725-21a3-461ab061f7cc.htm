    Stl025Report Class

    Represents a report that contains a market participant’s details for metering error adjustment amounts for Market Participants that generate electricity containing the changed IEQ quantities and the Generation Metering Error Adjustments for each Market Network Node belonging to the Market Participant broken down by period.
