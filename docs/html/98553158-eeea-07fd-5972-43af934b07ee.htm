    Remarks

    The Retailer’s VCRP and VCP values will be based on MSSL’s VCRP and VCP values respectively and the VCQ and VCSC values will be displayed as zeros. The VCQ has been updated to display 5 decimal places. MSSL’s VCP and VCQ values will be based on the Balance Vesting Price and Balance Vesting Quantity accordingly, while the VCSC values will be based on Balance data, LNG data and Tendered data.
