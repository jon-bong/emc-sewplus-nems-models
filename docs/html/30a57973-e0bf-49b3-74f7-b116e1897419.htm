    Emc.SewPlus.Nems.Models.Submissions Namespace

    Definitions of common classes and enumerations used by all submission classes.

    Classes

    Submission Represents a submission or pre-validation.
    SubmissionBatchResultSet Represents the set of details of a submission batch in response to asubmission history request.
    SubmissionEntry Represents the set of details in a submission or pre-validation.
    SubmissionRetrievalCriteria Represents a set of criteria to retrieve a submission.
    SubmissionRetrievalResultSet A result set representing retrieved submission details.
    SubmissionValidationMessage Represents a submission or pre-validation.
    SubmissionValidationResult Represents a string-formatted XML element (called report) generated for each submission containing the validation result of the corresponding submission node element with respect to the order of the elements in the submission XML file.
    SubmissionValidationStatus Represents the set of validation details in a submission.

    SubmissionTypeIdentifier Submission type identifiers.
