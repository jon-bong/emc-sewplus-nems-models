    Emc.SewPlus.Nems.Models.Reports.Mcr Namespace

    Definitions of Market Clearing Reports (MCR) classes.

    Classes

    MarketClearingRunReports The set of Market Clearing Run (MCR) reports.
    Mcr001Report Represents a report that retrieves the details of approved market clearing runs that occurred on a particular day (i.e. the runs that happened that day).
    Mcr010Report Represents a report that retrieves the USEP and other aggregate results of an individual market clearing run.
    Mcr011Report Represents a report that retrieves a report of projected prices, as calculated by a particular market clearing run.
    Mcr012Report Represents a report that retrieves required ancillary services and prices of reserve and regulation for a particular market clearing run.
    Mcr013Report Represents a report that has projected prices by provider group for a particular market clearing run.
    Mcr020Report Represents a report that retrieves the volumes of energy, reserve and regulation by network node for a particular market clearing run and the result set is restricted to those nodes owned by the market participant.
    Mcr021Report Represents a report that retrieves the scheduled generation dispatched by market clearing engine of an individual market clearing run.
    Mcr022Report Represents a report that retrieves the security constraints applied in market clearing engine of an individual market clearing run.
    Mcr023Report Represents a report that retrieves the risk adjustment factor applied in market clearing engine of an individual market clearing run.
    Mcr025Report Represents a report that retrieves the estimated Reserve Responsibility Shares (RRS) by Facility for a particular market clearing run and the result set is restricted to those Facility owned by the market participant.
